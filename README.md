# Chemistry_Python_Modules
This collection of Python modules accompanies the publication "Visualizing Chemical Principles Using Interactive Python Modules." These modules are intended to assist instructors with introducing students to chemical principles and to facilitate the creation of problems for students. 

A full description of the features and functionality of each module is given in the dedicated features guide included in this repository and in the Supporting Information of the original publication. Select example physical data is included to facilitate instructors' use of these programs.
